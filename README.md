### What I learned

While building this project, I practiced creating a centered card layout using CSS Flexbox. I also learned how useful `max-width` and percentage widths can be for making a component feel responsive without needing a lot of complicated CSS.

One important thing I practiced was separating the card into smaller parts, such as:

- The main card container
- The article image
- The category tag
- The title and summary text
- The author section

This helped me understand how HTML structure and CSS styling work together.

I also practiced using hover styles, such as changing the title color when the user hovers over it.

### Continued development

In future projects, I want to keep improving:
